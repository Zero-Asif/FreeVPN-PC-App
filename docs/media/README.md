# docs/media

Every picture in the README lives here, and every one of them was generated by a
script in `.build/` that you can run yourself. Nothing in this folder is fetched
from a third party when someone reads the README: no shields.io, no
capsule-render, no CDN. A page whose headline claim is that the app talks to
`127.0.0.1` should not make its readers talk to anyone else.

## Regenerating everything

```bash
node .build/make-badges.js
node_modules/electron/dist/electron.exe .build/probe-readme-shots.js
node_modules/electron/dist/electron.exe .build/probe-readme-popup.js
node_modules/electron/dist/electron.exe .build/probe-readme-art.js
```

The first three write files here. The fourth writes nothing here — it is the
gate: it renders every `.svg` in this folder the way GitHub will and fails if
one of them is broken. Previews land in `.build/art-preview/`, which is not
committed.

## What in the pictures is not real

The pixels are the shipping UI. Six values in them are fixtures, and this is
the complete list — nothing else in any image differs from what you get.

* **The country table.** Exit counts and bandwidth are invented, though the
  shape is exactly what `get-realtime-status` returns. Real numbers change hour
  to hour and would date the pictures; they also say something about the machine
  they were read on.
* **Home is London, GB.** Fixed at 51.5074, −0.1278. The idle globe centres on
  wherever you actually are, and a maintainer's home town does not belong in a
  public README.
* **The connected country is Japan.** One country had to be chosen for the
  connected shots. Any of the 74 looks the same.
* **The log viewer shows `C:\Users\you\…`.** A real path carries a real
  username.
* **The split-tunnel placeholder reads `e.g. mybank.example; intranet.local`.**
  What ships is `e.g. bkash.com; netflix.com` in `index.html:123` and
  `e.g. bkash.com; bank.com.bd` in `Extension/popup.html:474`. Both harnesses
  override it, because a screenshot in a privacy README should not name
  somebody else's bank or somebody else's streaming service.
* **The `BEST` badge sits on the United States.** The harness answers
  `get-fastest-server` with `us`; the shipping handler at `main.js:1896` answers
  `sg` unconditionally, because it is a stub. See the defect below — the badge
  is not a measurement in either place, and the README does not describe it as
  a feature.

Two things the screenshots show are real defects, kept in frame rather than
airbrushed out, and reported instead of quietly patched. A third is invisible in
the pictures but is the reason the badge above is a fixture:

* `09-comes-back.png` — the footer says "Nothing is connected right now…" while
  the body says "You are currently connected through India." The ask raised at
  `main.js:3014` passes no `foot`, so `renderer.js:664` falls back to the idle
  line.
* `30-welcome.png` — a full stop sits on its own line. `welcome.html`'s
  `ol.steps li b { display: block; }` also matches the inline
  `<b>FreeProxy VPN Extension</b>` on line 257.
* `main.js:1896` — `get-fastest-server` returns `{ best: 'sg', others: ['hk',
  'jp'] }` no matter what, and `renderer.js:824` paints a `BEST` badge from it.
  Nothing is timed. Either measure it or drop the badge.

## What the art gate refuses

`.build/probe-readme-art.js` loads each SVG from a blob into an `<img>` — the
same sandbox GitHub gives it — on white **and** on `#0d1117`, at the file's own
intrinsic size, one frame into its animation. It fails the build on:

* XML that will not parse, including a `--` inside a comment, which is illegal
* a `<script>` element or an inline `on…=` handler (GitHub strips them, so art
  that needs one is art that is broken)
* an `http(s)` URL, a `url()` pointing off this disk, or a raster `<image>`
* a URL *printed as a label* whose host is not `127.0.0.1` or `localhost`
* a missing `viewBox`, or neither `role="img"` nor a `<title>`
* words clipped by the viewBox (decorative bleed is allowed and expected)
* text buried under a later opaque `<rect>`, or overlapping other text
* a gradient in `objectBoundingBox` units on a shape with a zero-width or
  zero-height box, which paints nothing at all — a horizontal rule is exactly
  that shape, and two of these were silently invisible until the check existed
* a preview whose PNG is too small for its area to contain anything
* any network request leaving the machine while rendering

If you edit an SVG here, run the gate. `0 failed.` is the only acceptable
result.

This document is checked as well, by the two gates that cover every markdown file
in the repository: `.build/probe-readme-links.js` for its links, its in-page
anchors and its `file#Lnnn` references, and `.build/probe-md-html.js` for the raw
HTML in it. Both are in the list to run before opening a pull request.
