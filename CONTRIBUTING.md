# Contributing to FreeProxy VPN

First off, thank you for considering contributing to FreeProxy VPN! It's people like you that make FreeProxy such a great tool for privacy.

## 1. How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report. Following these guidelines helps maintainers understand your report, reproduce the behavior, and find related reports.
* **Use the GitHub issue search** — check if the issue has already been reported.
* **Check if the issue has been fixed** — try to reproduce it using the latest `main` branch.
* **Provide details** — include your OS, Node/Electron version, Tor logs if applicable, and the steps to reproduce the bug.

### Suggesting Enhancements
* **Use a clear and descriptive title** for the issue to identify the suggestion.
* **Provide a step-by-step description** of the suggested enhancement in as many details as possible.
* **Explain why this enhancement would be useful** to most FreeProxy VPN users.

### Pull Requests
* Fill in the required PR template (if available).
* Include screenshots or short videos in your pull request whenever possible if your changes affect the UI.
* Ensure your code doesn't break the existing 15-second Tor verification logic.

## 2. Local Development Setup

To set up your local development environment:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Zero-Asif/FreeVPN-PC-App.git
    ```
2.  **Navigate to the directory:**
    ```bash
    cd FreeVPN-PC-App
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Run the app:**
    ```bash
    npm start
    ```

## 3. Styleguides

### Git Commit Messages
* Use the present tense ("Add feature" not "Added feature").
* Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
* Limit the first line to 72 characters or less.
* Reference issues and pull requests liberally after the first line.

### Branch Naming Convention
* `feature/feature-name` for new features.
* `bugfix/bug-name` for bug fixes.
* `docs/document-name` for documentation updates.

Thank you for contributing to open-source privacy!
